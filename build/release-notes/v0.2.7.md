## 更新内容

本版聚焦**「修了没用」的那几类**：破解工具残留清不干净、诊断把「没扫全」说成「没问题」、
自动登录在部分账户写法下填了密码却不提交。另外补上了 UU 切换与分身端的一批边界问题。

### 诊断与修复：清理开机项更彻底

装过 RDP 破解工具的机器，只还原 `termsrv.dll` 是没用的——留在计划任务里的补丁会在下次开机
把它写回去，表现就是「修好了，重启又坏」。

- 确认 `termsrv.dll` 被篡改后，**连 `\Microsoft\` 子树里的任务内容一起读**。系统自带任务有一千多个，
  平时不读，只有文件真被改过时才付这个代价。
- **深扫会「黏住」**：从「确认被篡改」那一刻起保持深扫，直到「文件已还原 + 一次深扫零命中 +
  期间没有新的篡改」才退回浅扫。修复时缓存刚好过期不会降级漏扫，修复时没删掉的任务也不会凭空消失。
- 修复开始前同样记一次义务，并写进设置跨重启保持。
- 清理开机项失败不再算整体成功——文件还原了、任务还在，下次开机照样写回补丁。

### 诊断与修复：「没扫全」不再被当成「没问题」

- 计划任务改成逐目录遍历：某个子目录被拒绝访问不再让整轮扫描整体失败；被拒目录、读不到的任务定义、
  其它用户的自启项枚举失败，**全部计入「扫描不完整」**。
- 「全部检查项」区分三种状态：`未读取（需要管理员权限）` / `有位置未能读取` / 具体命中数。
  检查项由 13 项增至 **14 项**，扫描不完整**单列一条**，常规视图也能看见。
- 清理时若扫描不完整且没有命中，不再报「没有需要清理的项」，改为提示以管理员身份重检。

### 诊断与修复：备份、sfc 与服务处理

- 计划任务备份改用 UTF-16 落盘（`schtasks` 输出的 XML 声明 UTF-16，字节却是本地代码页，
  按 UTF-8 存回去中文任务名对不上，真要恢复时读不对）；备份文件名加短哈希，避免长路径写不进去、
  以及 `rdpwrap:a` / `rdpwrap?a` 归一后同名互相覆盖。
- 停服务超时**先等服务真正停下**再决定：停稳了继续用备份覆盖，确实停不下才退到 `sfc /scannow`。
  停不下来的原因（如 1051）与「服务恢复失败」都会进结论，不再只留在日志里。
- `sfc /verifyfile` 串行化，并对校验加世代号：点「重新检测」会**真正重新校验**（原来 5 分钟内是旧结论）；
  校验未出结论时不再给 `termsrv.dll` 那条打绿勾。

### 自动登录

- **确认按钮只点名字对得上的那个**（中、繁、英、日、韩、俄、西共 12 种写法），
  不再「取第一个可用按钮」——遇到不认识的语言会替用户点「取消」，还被记成「已填充」不再重试。
- 身份解析：优先用设置里填的账户；UPN 按「是否加入 AD 域 / 是否加入 Entra」区分工作账户与微软账户；
  支持 `MicrosoftAccount\邮箱` 与 `域\用户` 两种显式写法。
- 校验期间锁住密码框，避免校验的是旧值、返回给调用方的是新值；日志不再写账户名。

### UU 视角切换

- **恢复义务跨切换保留**：杀掉串流端后没恢复时，下一次切换不会再把它清掉，避免两条路径都报成功而设备离线。
- **停了一定会启**：`stop` 之后的启动不受取消影响，等真正到 `STOPPED` 再 `start`，失败会再试一次；
  命令成败按服务真实状态判定（`sc` 的退出码不可信），每条命令 30 秒硬上限。
- 恢复循环与手动重启共用一把闸门；自动恢复在闸门内复查串流端，已经回来就跳过，不打断正在用的串流；
  上一轮恢复没结束就不再开始新切换。
- 失败时区分「停不下来」和「起不来」，不再一律说两句都失败；杀不掉串流端时会把分身连回来（不最小化窗口）。

### 分身端与后台线程

- 自检（`--test`）不再顺手杀掉正在跑的旧代理，遇到已在运行的代理返回 3，不再假装自检通过。
- 结束旧进程后**等它真正退出**再抢互斥量（`Kill` 是异步的）。
- 心跳改为「写临时文件再替换」：主程序不会再撞上被截断的空文件把在线判成离线。
- 安装失败会回滚旧 exe 并如实上报（旧代理仍可用，轮询继续）。
- 热键解析补齐 `F1`~`F24`、符号键与命名键，与主程序一致。
- 环境预检移到后台（深扫要读上千个 XML，原来会卡住界面）；启动、断开、重连等入口自身切回 UI 线程，
  UU 切回分身的兜底此前正死在跨线程访问上。

### 其他

- 取消关闭后工具栏不再处于「已隐藏」状态；窗口隐藏时收掉工具栏与通知浮层，恢复时按需重开
  （通知只在未超时时重开，隐藏期间的新通知也不会浮在桌面上）。
- 英文译文随版本更新为 `Localization/DesktopTwin-0.2.7-EN.lng`。

完整变更见 [CHANGELOG](https://github.com/batvbs/DesktopTwin/blob/main/CHANGELOG.md)。
