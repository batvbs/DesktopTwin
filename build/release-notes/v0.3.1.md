## 更新内容

本版加入 **UU 视角锁定**，并修掉几个影响日常使用的问题。

### 新增：UU 视角锁定

UU 的串流端由 SYSTEM 服务按「会话号最大的已登录桌面」挑选——启动桌面分身时它会自动跳到分身，手机端就看不到主机画面了。开启「UU 视角锁定」后，程序监听会话与串流端的变化，发现串流端离开记录的位置就自动纠正回主机。

- 纠正断开分身后会按会话状态挂回后台：分身还在就自动连回来（游戏不中断），已经注销才不连
- 用户在分身内开始菜单「断开连接」时，自动把视角拉回主机，不再让人对着黑屏
- 与「UU 视角切换」独立开关；只开锁定时记录值固定为主机，不注册热键
- 手动「修复 UU 串流」进行中不纠正；手动切换落定后的 3 秒宽限期跳过纠正
- 关闭「视角切换」时一并结束分身端 agent，不再残留热键占用

### 修复：注销分身之后手机端显示离线

注销分身会触发 UU 服务重启串流端；视角在主机时这次重拉会进入僵尸态（进程还在、但不再注册云端）。退出流程现在会在注销分身后重启一次 UU 服务，清掉这个状态。

### 修复：自动重连会改动窗口状态

改分辨率、静音、UU 切换触发的重连不再动窗口：全屏保持全屏、最小化保持最小化、隐藏保持隐藏，也不抢焦点。

### 改进：会话操作生命周期统一

启动、切换、恢复、注销统一走同一套会话操作生命周期；服务恢复的等待循环带超时，卡在「停止中」不再无限等待。

完整变更见 [CHANGELOG](https://github.com/batvbs/DesktopTwin/blob/main/CHANGELOG.md)。
